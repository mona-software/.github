## MONA Pay — nhánh mã nguồn mở

> MONA Pay là cổng thanh toán và API ngân hàng của The MONA Group, giúp doanh nghiệp Việt Nam nhận và xác nhận tiền chuyển khoản theo thời gian thực qua tài khoản ảo (VA), VietQR, webhook và Telegram — thiết kế để cả lập trình viên lẫn AI agent tích hợp trong vài phút.

| Repo | Là gì |
|---|---|
| `monapay-node` | SDK Node.js / TypeScript (`@monapay/node`) |
| `monapay-python` | SDK Python (`monapay`) |
| `monapay-php` | SDK PHP (`monapay/php-sdk`) |
| `monapay-mcp` | MCP server cho Claude Code / Cursor / Codex |
| `monapay-cli` | CLI: `monapay webhook listen`, tạo QR, tra giao dịch |
| `woocommerce-monapay` | Plugin WooCommerce: chuyển khoản VietQR tự xác nhận |
| `monapay-examples` | Ví dụ Next.js · Express · NestJS · Laravel · Django · FastAPI · Spring Boot · Go |

**Bắt đầu 5 phút:** đăng ký tại https://my.monapay.vn/auth?mode=register → tạo API key → đọc https://monapay.vn/docs (máy đọc: https://monapay.vn/llms.txt · https://monapay.vn/openapi.json).
